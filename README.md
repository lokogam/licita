# Módulo de Licitaciones

Módulo para crear, editar, listar y consultar licitaciones (ofertas), con carga de documentos y exportación a Excel.

- **Backend:** PHP 8.2 sin framework, patrón MVC, Eloquent standalone como ORM, API REST documentada con OpenAPI/Swagger.
- **Frontend:** Vue 3 + Vite, Axios, Bootstrap 5.3.
- **Base de datos:** MySQL 8.
- **Infraestructura:** Docker (un Dockerfile multi-stage + Docker Compose).
